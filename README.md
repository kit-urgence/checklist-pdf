## Contenu du kit 72h

Le kit d'urgence 72h recommandé couvre :

- **Eau** : 3 litres/personne/jour minimum
- **Alimentation** : conserves longue durée, barres énergétiques
- **Éclairage** : lampe frontale + piles de rechange
- **Communication** : radio à piles ou manivelle, sifflet
- **Premiers secours** : trousse de premiers soins complète
- **Documents** : copies des papiers d'identité et assurances
- **Argent liquide** : en cas de panne des distributeurs
- **Médicaments** : traitements en cours pour 72h minimum
